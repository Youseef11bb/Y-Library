# مكتبتي — تطبيق مكتبة PDF شخصية

تطبيق مكتبة PDF مبني بـ React + Vite، بيشتغل بالكامل من غير إنترنت بعد ما تفتحه أول مرة،
وكل الكتب والأقسام بتتخزن جوه التابلت نفسه (IndexedDB) — مفيش سيرفر ولا رفع ملفات لحد تاني.

## طريقة التشغيل والتعديل (VSCode)

1. افتح الفولدر ده في VSCode.
2. افتح Terminal جواه واكتب:
   ```
   npm install
   ```
   (مرة واحدة بس، أول ما تفتح المشروع)
3. عشان تشغّل وتشوف التطبيق وانت بتعدّل:
   ```
   npm run dev
   ```
   هيديك رابط زي `http://localhost:5173` — افتحه في المتصفح على جهازك عشان تجرب.

## طريقة تشغيله على تابلت الـA7 فعليًا (من غير Android Studio)

أسهل طريقة إنك تخليه "PWA" — يعني تطبيق ويب بيتثبت على الشاشة الرئيسية زي أي تطبيق عادي،
وده بيشتغل offline بعد أول فتحة، والمشروع مظبوط عليه بالفعل.

1. شغّل:
   ```
   npm run build
   npm run preview -- --host
   ```
2. هيديك رابط فيه IP زي `http://192.168.1.5:4173` — لازم التابلت واللابتوب على نفس الـWiFi.
3. افتح الرابط ده في Chrome على التابلت.
4. من قايمة Chrome (٣ نقط) دوس "إضافة إلى الشاشة الرئيسية" (Add to Home screen) أو هيظهرلك اقتراح تثبيت تلقائي.
5. هيتحط أيقونة "مكتبتي" على الشاشة الرئيسية، وتفتح زي أي تطبيق عادي بدون شريط متصفح.

> ملحوظة: طريقة الـPWA دي هي الأنسب ليك لأنك محتاج VSCode بس. لو حبيت بعدين تطلع APK حقيقي
> (يتثبت زي أي تطبيق من ملف، أو يترفع على المتجر)، ده هيحتاج تثبيت Android Studio مرة واحدة
> (أداة مجانية من جوجل) لأن بناء ملف APK لازم أدوات أندرويد نفسها — مفيش طريقة تتجنب الخطوة دي
> بس هي خطوة نادرة (تعملها مرة واحدة وتنسى، مش كل مرة بتعدل الكود). لو قررت تعمل كده، المشروع
> جاهز أصلاً بـCapacitor (capacitor.config.ts) وهقولك الخطوات بالظبط وقتها.

## هيكل المشروع

- `src/pages/` — الشاشات: Home (الرئيسية), Library (المكتبة), Search (بحث), Reader (قارئ PDF), BookDetails (تفاصيل الكتاب)
- `src/components/` — أجزاء الواجهة القابلة لإعادة الاستخدام (كارت الكتاب، الشريط السفلي، الأقسام، مودال الإضافة)
- `src/db.ts` — كل التعامل مع التخزين (IndexedDB): إضافة/حذف/تعديل كتب وأقسام
- `src/lib/pdf.ts` — توليد غلاف الكتاب وعرض صفحات الـPDF (pdf.js)
- `tailwind.config.js` — ألوان وخطوط التصميم (Lumina Glass) اللي جايه من الثيم بتاعك

## إزاي تضيف كتاب

من شاشة "المكتبة" دوس "إضافة كتاب"، اختار ملف/ملفات PDF من التابلت، عدّل العنوان والمؤلف
لو حابب، اختار القسم (أو سيبه بدون تصنيف)، ودوس حفظ.

## إزاي تتحكم في الأقسام

من شاشة "المكتبة"، جنب فلاتر الأقسام فيه زرار "قسم جديد" — اكتب الاسم ودوس Enter.
لو عايز تمسح قسم، حوّم على الفلتر بتاعه هيظهر × صغير فوقه.
